One short rant about a small everyday annoyance, written for a judge
with a famously short temper: the smoke alarm that only ever chirps
its low-battery warning at 3 a.m.

## The rant

> My smoke alarm has never chirped at noon. Not once. It waits until 3 a.m., beeps a single time, then goes silent for an hour so I lie there wondering if I dreamed it. Last night I stood on a chair in the dark, holding a broom, negotiating with a plastic disc on my ceiling. The disc won. It is still up there, fully charged with contempt.

Three hundred and thirty-eight characters, one paragraph, no padding:
a concrete annoyance, a 3 a.m. ambush, and a loser holding a broom —
the anger is shared, not performed, because everyone has met this alarm.

## How it runs

`main.py` writes that single rant to `entry.txt` in the output
directory (`MAKEFUN_OUTPUT_DIR`, or `/output` by default), directly
with mode `0644` so the grader can read it.

```sh
python3 main.py
```
